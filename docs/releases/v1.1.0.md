# CHAOS;HEAD NOAH — Traducción al español v1.1.0

Esta actualización añade **nueve recursos gráficos de interfaz en español** a la traducción completa de `v1.0.0`: configuración, biblioteca, música, dos paneles de accesos rápidos, TIPS, álbum, miniaturas del álbum y backlog. El texto narrativo de `v1.0.0` permanece intacto.

Los nuevos gráficos se instalan en `languagebarrier/c0data.cpk` de Committee of Zero 1.1.3. `system_eng.cpk` y `manual_eng.cpk` no se modifican.

### Instalación

1. Usa CHAOS;HEAD NOAH para Steam con [Committee of Zero Overhaul Patch 1.1.3](https://sonome.dareno.me/projects/chn-patch.html) instalado.
2. Descarga `CHAOS-HEAD-NOAH-ES-Setup.exe` de esta release y, si quieres verificar la descarga, usa `SHA256SUMS.txt`.
3. Ejecuta el instalador. Acepta una instalación CoZ compatible limpia o una instalación española `v1.0.0`; al actualizar, conserva el backup histórico.

La instalación puede tardar más que la anterior: reconstruye, respalda y verifica `c0data.cpk`, de aproximadamente 2,26 GB. Espera a que termine. El instalador no inicia el juego ni el launcher de CoZ. Puedes usar **Restaurar original** para recuperar los CPK originales verificados.
